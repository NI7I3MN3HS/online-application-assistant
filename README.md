# 网申助手

[English](README.en.md) · [问题反馈](https://github.com/NI7I3MN3HS/online-application-assistant/issues)

<p align="center">
  <img src="assets/logo.png" alt="网申助手 · Online Application Assistant" width="720" />
</p>

本地简历管理与网申填表扩展，支持简历导入、字段记忆和投递记录。维护一份资料，在招聘页面点击填写，核对后自行提交。

当前版本 **v1.5.1**，支持 Chrome、Edge、Brave 等 Chromium 浏览器。核心功能无需 API Key。

## 主要功能

- **简历资料**：按基本信息、教育、工作、项目等分类管理，支持多条经历和额外字段。
- **简历导入**：支持 PDF、DOCX、TXT 和粘贴文字，扫描 PDF 可使用本地中英文 OCR；解析后核对、勾选并保存。
- **网页填写**：使用本地规则、字段记忆和可选 AI 匹配字段；网页资料面板支持搜索与复制。
- **字段记忆**：自动学习成功匹配，也可从手动填写的页面学习、补录缺失资料并确认成组字段。
- **投递记录**：填写后自动记录公司、岗位和来源，支持手动新增、编辑、筛选、备注及自定义状态。

## 安装

1. 从[本仓库](https://github.com/NI7I3MN3HS/online-application-assistant)下载完整安装包并解压，或克隆源码。
2. 打开 `chrome://extensions/`、`edge://extensions/` 或 `brave://extensions/`。
3. 开启 `开发者模式`，点击 `加载已解压的扩展程序`。
4. 选择直接包含 `manifest.json` 的目录，固定扩展图标。

无需构建或安装 Node.js、Python。请完整保留安装文件及 `vendor/` 依赖，并将目录放在长期保留的位置。

## 使用

1. 打开 `简历资料`，手动录入或点击 `导入简历`，核对后保存。
2. 打开招聘网站的申请表单，点击扩展图标，再点击 `开始填写`。
3. 检查结果：**绿色表示已填写，橙色表示待处理**。补充未填字段并自行上传附件。
4. 核对右下角记录卡片中的公司和岗位，补全缺失信息并保存。
5. 自己提交网页表单，再将记录状态手动改为 `已投递`。

进入新页面或下一步表单后，需要再次点击填写。扩展不会自动提交申请。体验功能可通过资料备份入口导入 [sample-profile.json](sample-profile.json)。

### 简历导入

在导入预览中对照原文编辑并勾选字段。默认保留已有值、只补空缺，也可覆盖所选字段；新经历追加，重复内容跳过。支持撤销最近一次导入，后续已修改资料时会阻止直接撤销。

文件最大 10 MB；PDF 最多 30 页，其中最多 10 页使用 OCR；文本上限为 200,000 个字符。旧版 `.doc` 请转为 `.docx`，独立图片请先转为 PDF，加密 PDF 请先解除保护。扫描件和复杂版式需要人工核对。

### 字段记忆

成功填写后自动保存可确认的映射。手动填写页面后，可点击 `从本页学习`，勾选缺失的普通资料进行补录；重复字段需确认对应的经历顺序。

记忆只保存字段映射和使用统计，不保存简历具体值。支持启停、删除单条和清空全部，上限为 500 条；有歧义的匹配会跳过，上传和密码类字段不参与学习。

### 投递记录

至少成功填写一个字段后自动保存记录；公司或岗位无法确定时显示 `待补全`，可手动修改。重复填写会更新已有记录，保留人工修改、状态和备注；再次投递可手动另建记录。

新记录状态固定为 **填写**，不会自动变成已投递。预设状态为 `填写、已投递、笔试、面试、Offer、未通过、已撤回`，支持自定义；删除已使用的状态需要指定迁移目标。记录时间和最近填写时间不代表实际投递时间。

## 可选 AI

在 `设置 → API 页面分析` 配置 OpenAI 兼容接口或自定义 API，填写地址、模型和凭据；测试成功后仍需保存配置。

不配置 API 也可使用本地规则和字段记忆。AI 请求包含字段目录、表单结构和相关页面上下文，不附带本机简历具体值，请求发送到你配置的服务商。

## 数据与隐私

- 简历资料、字段记忆、投递记录和 API Key 保存在当前浏览器的本机扩展存储中。
- 简历解析和 OCR 在本机完成，不上传简历文件或解析原文。
- 扫描与填写由用户操作触发，不监控浏览历史；可选 AI 会请求指定接口，版本检查会访问 GitHub。
- 填入网页的资料可被目标网站读取，请在提交前核对。

在 `设置 → 数据与备份` 导入或导出简历 JSON。**备份不包含投递记录和字段记忆，这两类数据目前没有独立导出入口。** `清空资料和 API 设置` 会保留投递记录和字段记忆。

## 更新

从[本仓库](https://github.com/NI7I3MN3HS/online-application-assistant)获取新版本，备份简历后关闭扩展页面，将文件覆盖到原安装目录，在扩展管理页点击 `重新加载`，再刷新招聘网页。保留原目录和浏览器用户配置，避免因卸载或重复安装失去原数据。

内置更新检查会读取本项目的 GitHub Release。
