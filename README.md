# OpenJobAutofill-FieldMemory

[English README](README.en.md)

基于开源项目 [OpenJobAutofill](https://github.com/Br1an67/OpenJobAutofill)（MIT 协议）的增强 fork，在官方全部功能之上新增 **字段记忆（Field Memory）**：让插件记住"哪个字段该从资料库哪里取值"，下次遇到同名字段直接回填，不再反复询问本地规则和 AI。

官方原版的定位不变：资料库填表、不自动投递、AI 只辅助识别字段含义、简历具体值不出本机。

## 这个 fork 多了什么：字段记忆

网申表单里，「生源地」「籍贯」「毕业院校」「期望城市」这类字段在不同网站反复出现，但叫法零散，本地规则和 AI 不一定每次都认得出。字段记忆解决的正是这一步：

- **自动学习**：某次「开始填写」中一个字段自动填写成功，"页面字段标签 → 资料字段路径"的映射就自动入记忆；下次同名字段直接回填。
- **从本页学习**：你手动填完一页后，点弹窗里的「从本页学习」，插件读取页面当前值、与本机资料库做归一化匹配，把映射写进记忆。值不在资料库里的字段会列出名字，提示你去设置页补录——补一次，以后就能自动填。
- **本机管理**：设置页有启用开关、记忆条数、逐条删除和一键清空。

### 安全限制

- 只记"字段标签 → 资料字段路径"的映射和少量统计（最近网站、成功次数），**不记任何资料值**，与官方隐私原则一致。
- 同一页面出现多次的同名字段（如多条教育经历各自的「学校」）不读也不写记忆，避免错位。
- 记忆候选仍经过官方的语义兼容性检查，类别冲突会被拒绝；只补空缺，不覆盖本地规则和 AI 已有的匹配。
- 「从本页学习」跳过上传/附件/照片/密码类字段；多资料值歧义且无法定位时跳过并报告。
- 记忆容量上限 500 条，按最近使用淘汰。

## 安装（开发者模式）

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions/`（或 Brave 的 `brave://extensions/`）。
3. 开启右上角 `Developer mode`，点击 `Load unpacked`，选择本仓库目录。
4. 固定扩展图标，到设置页填写你的简历资料即可使用。

不需要安装依赖，也不需要构建。

## 使用

与官方 OpenJobAutofill 完全一致（详见官方 [README](https://github.com/Br1an67/OpenJobAutofill)）：设置页维护本机资料 → 打开招聘网站表单页 → 弹窗点「开始填写」→ 按绿色（已填写）/橙色（待处理）标记检查 → 自己确认提交。

新增的「从本页学习」用法：在某个网站第一次手动填完后点一下，这个站特有的字段叫法就被学会了，下次开始填写时自动覆盖。

AI 是可选的：不配置 API 也能用（本地规则 + 字段记忆）；配置 OpenAI 兼容 API 后识别能力更强。AI 请求只包含字段名称，不含资料值。

## ⚠️ 更新须知

插件内置的更新检查指向官方仓库的 Release。**如果按提示下载官方包覆盖安装，字段记忆功能会丢失**（资料本身保留在浏览器存储里）。想继续用字段记忆，请以本仓库为准更新。
