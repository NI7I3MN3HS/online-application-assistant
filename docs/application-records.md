# 投递记录

## 使用

重新加载扩展，然后在招聘网页点击「开始填写」。至少成功填写一项后，插件会自动保存记录，并在右下角显示可编辑卡片。即使插件弹窗已关闭，网页中的填写任务仍负责记录。

新记录的状态是 **填写**，不代表网站已收到申请。公司和岗位能识别就自动填入，信息不足时显示待补全；可直接修改并保存，或点「查看全部」进入独立管理页。插件弹窗的「投递记录」显示当前网站最近三条记录。

管理页支持：

- 搜索公司、岗位、网站、网页标题及备注，按状态、网站或待补全筛选。
- 手动新增、修改和删除记录，打开来源网页。手动新增允许补记旧申请或建立再次投递的独立记录。
- 手动切换填写、已投递、笔试、面试、Offer、未通过、已撤回。
- 管理自定义状态：新增、改名、排序和删除。初始状态「填写」保留；删除正在使用的状态必须指定迁移目标。

记录时间、最近填写时间和填写次数只描述插件记录到的行为，不能证明实际投递成功。后续重复填写不会自动将状态改为已投递，也不会覆盖你保存的公司、岗位或备注。

## 识别与去重

识别顺序是当前职位的 JobPosting JSON-LD、明确的职位/雇主摘要、网页标题及分享标题。多个结构化职位不能唯一匹配时不随意选第一个；表单输入值、历史工作单位、简历求职意向不用于推断本次目标职位。

同一站点/租户的同一职位 ID 优先合并，没有 ID 时使用明确的职位链接和公司岗位。保留职位参数与 SPA hash，去除已知追踪和鉴权参数。未知岗位只在同一页面实例内去重，不跨页面猜测合并。手动新增不受自动去重限制；后续填写匹配到多条同岗记录时，更新最近建立的一条。每次填写有独立事件标识，在保留的最近 1000 个去重事件窗口内，重试同一事件不会重复计数。

网页在填写过程中切换路由、标题或已识别岗位时，会跳过该次自动记录以避免串岗，可在管理页手动补记。公司别名、非标准岗位参数及缺少职位上下文的多步骤站点仍可能需要手动整理；不能保证覆盖所有招聘网站模板。

## 存储和兼容

数据在 `chrome.storage.local.applicationsV1` 中，包含版本、记录、状态定义及有限的去重事件列表，不上传服务器、不调用 AI、不要求新的浏览历史或常驻站点权限。

- `src/applications/model.mjs`：数据校验、自动合并、人工字段保护、版本冲突、状态迁移和串行写队列。
- `src/applications/context.js`：共享的纯文本/URL 处理与只读页面元数据采集。
- `src/applications/capture.js`：独立内容脚本中的自动记录及 Shadow DOM 卡片。
- `src/applications.html`、`src/applications/page.mjs`：独立管理页。
- 后台消息：`OJAF_RECORD_APPLICATION`、`OJAF_LIST_APPLICATIONS`、`OJAF_GET_APPLICATION`、`OJAF_SAVE_APPLICATION`、`OJAF_DELETE_APPLICATION`、`OJAF_SAVE_APPLICATION_STATUSES`、`OJAF_OPEN_APPLICATIONS`。

所有写入经后台串行执行；记录编辑检查记录版本，状态定义检查状态版本。发生冲突时保留编辑草稿并提示重新加载，不静默覆盖。状态删除和相关记录迁移在同一次存储写入中完成。成功写入之后才显示已记录，失败时保留卡片并支持重试。

「清空资料和 API 设置」只删除简历与 API 配置，投递记录和字段记忆保留。原简历备份格式不变，本功能未增加云同步、投递自动提交、邮箱追踪或提醒。

## 验证

自动测试：`npm test`。包含职位去重、共享 ATS 租户隔离、JSON-LD 歧义、中文标题顺序、SPA/URL 清理、人工字段与状态保护、重复事件、并发写入、版本冲突、状态迁移和存储失败恢复，同时回归已有简历/OCR/字段记忆测试。

真实扩展验证使用隔离 Edge 153 + 捆绑 Playwright；当前会话没有 Browser 插件技能。使用临时 localhost 夹具、临时扩展副本与测试浏览器目录，未修改用户浏览器授权。验证路径包括：

- 简历文字导入 → 18 个网页表单字段正确填入 → 自动记录目标公司岗位 → 卡片手动改状态 → 重复填写保留手动值。
- 独立管理页新增、编辑、搜索筛选、刷新保留；自定义状态新增/改名/排序/删除迁移。
- 双页面编辑冲突、未保存草稿保护；存储失败重试、正在编辑的卡片不误报再次记录成功。
- 缺失元数据、零成功、不同职位、填写中路由切换，以及清空简历后保留记录。
- 桌面 1440px、窄屏 390px；列表与状态排序的键盘焦点恢复。
- 在填写运行中关闭插件弹窗，网页仍继续保存记录并显示卡片。

本次 `npm test` 共 53 项通过，其中投递记录新增 19 项；真实扩展交互无页面脚本错误。设计审查的两项交互问题（键盘焦点、编辑中再次保存失败提示）已修复并复验。

测试没有代替用户提交任何申请。没有逐站验证所有真实招聘网站，也没有宣称记录本身能确认投递成功。
