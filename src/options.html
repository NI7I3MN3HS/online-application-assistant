首次使用 · 三步开始填写
  1. 导入简历，或按栏目补充资料。
  2. 点击“保存资料”，保存到本机。
  3. 打开招聘表单页，在插件中选择“开始填写”。

API 页面分析是可选增强；无需 API 也能使用本机规则。插件不会自动提交。

选择文件或粘贴简历

PDF、Word（.docx）、TXT，最大 10 MB / 30 页。扫描或文字转图形的 PDF 会自动在本机 OCR（最多 10 页），可能需要数十秒；识别后请核对姓名、数字和专业术语。
